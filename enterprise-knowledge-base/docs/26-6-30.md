### 任务 8 ✅ 流式生成改造 (SSE)

**修改文件**: `agents/nodes/generate.py`, `agents/customer/generate.py`

**变更**:
```python
# 旧: 同步调用，SSE 无法捕获 token
answer = call_llm_with_retry(llm, messages, max_retries=2)

# 新: 异步流式调用，SSE 可捕获 on_chat_model_stream 事件
chunks = []
async for chunk in llm.astream(messages):
    content = getattr(chunk, "content", "")
    if content:
        chunks.append(str(content))
answer = "".join(chunks)
```
- `api/agent/__init__.py` 的 SSE 端点 `/chat/stream` 现可通过 `graph.astream_events` 捕获流式 token

```bash
# 进入后端容器
docker compose exec backend bash

# 运行全部测试 (257 passed)
docker compose exec backend pytest tests/ -q --no-cov --ignore=tests/unit/test_checkpoint.py

# 查看后端日志
docker compose logs -f backend --tail=50

# 重建前端
docker compose up -d frontend --force-recreate

# 访问
# 前端: http://localhost:5173
# API 文档: http://localhost:8000/docs
# Grafana: http://localhost:3000 (admin/admin)
# MinIO: http://localhost:9001 (minioadmin/minioadmin)
```
