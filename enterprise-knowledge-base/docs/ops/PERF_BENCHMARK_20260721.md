## 六、瓶颈总结与优化建议

| 瓶颈 | 当前耗时 | 占全链路比 | 优化建议 |
|------|------|:---:|------|
| Reranker API | 168-534ms | ~25% | 候选数限制 20 条内；考虑本地 ONNX 推理 |
| LLM 首 Token | ~675ms | ~30% | DeepSeek 服务端优化；考虑量化小模型 |
| LLM 生成 | ~15-22s | ~40% | Streaming 缓解感知延迟 |
| Graph 构建 | 20-30s | 启动 | `lifespan` 预编译 + 缓存序列化 |
| Milvus Load | 偶发 10s | 首次 | 启动时预热 `preload_collections` |
| FAQ Embedding | ~300ms | FAQ 链路 | SiliconFlow batch API 复用 |
