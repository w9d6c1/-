# 最终用户使用指南

## 访问方式

### Web 端

打开浏览器访问 `https://<服务器地址>`，进入登录页面。

### 默认账号

首次使用请联系管理员获取账号。管理员可通过管理后台批量创建。

---

## 一、智能问答

### 内部知识问答

登录后，点击首页"智能问答"或左侧菜单"智能问答"，进入对话页面。

1. 在顶部切换栏选择 **"内部问答"**
2. 输入问题，按回车发送
3. 查看 AI 回答及置信度标签

**适用场景**：查询公司制度、技术规范、项目文档等内部知识。

**提示**：
- 置信度 ≥80%（绿色）：高可信度，可直接使用
- 置信度 50%-80%（橙色）：建议人工复核
- 置信度 <50%（红色）：建议查阅原始文档

### 客服咨询

切换至 **"客服咨询"** 模式，用于客户服务场景。

**适用场景**：产品问题、退换货流程、售后服务等。

### 用户反馈

每次对话后可对回答进行评价：

- 👍 点赞：回答准确有用
- 👎 踩：回答不准确或需改进（可填写具体建议）

系统会统计反馈数据，持续优化知识库质量。

## 二、管理后台

> ⚠️ 管理后台限内网访问，外网请使用 VPN。

管理员点击首页"管理后台"进入。

### 2.1 仪表盘

查看今日问答总数、FAQ 命中率、用户满意度、待审文档数等关键指标。

### 2.2 分类管理

创建/编辑/删除知识分类（如：人事制度、产品知识、客服流程）。

### 2.3 FAQ 管理

直接录入问答对：
1. 选择分类 → 输入问题 → 输入答案
2. 可选择标签、相似问句、生效时间
3. 保存后自动生效（无需重启）

**批量导入**：点击"批量导入"按钮，粘贴 `问题 | 答案` 格式的文本。

### 2.4 文档管理

上传长文档到知识库：
1. 点击"新建文档" → 填写标题和分类 → 创建
2. 点击"上传内容" → 粘贴或输入文档正文
3. 点击"分块确认" → 系统自动分块
4. 提交审核 → 管理员审核通过后上线

### 2.5 审核中心

审核待审批的文档：
- 通过：文档上线，知识可被检索
- 驳回：文档退回草稿状态

### 2.6 用户反馈管理

查看用户对 FAQ/文档的评价（点赞/踩），筛选分析反馈分布。

### 2.7 未命中问题管理

查看用户提问后未被知识库覆盖的问题：
- **转 FAQ**：点击"转为 FAQ"，AI 自动生成答案草稿
- **忽略**：标记为无需处理
- **待处理**：跟踪未覆盖知识缺口

### 2.8 词库管理

- **同义词**：配置同义词映射（如"远程办公 → 居家办公"），提升检索准确率
- **敏感词**：配置禁答词（拦截）或敏感词（过滤）

### 2.9 角色权限

配置不同角色可访问的知识范围（public/customer/internal）。

## 三、常见操作

| 操作 | 路径 | 适用角色 |
|------|------|---------|
| 查询知识 | 首页 → 智能问答 | 所有人 |
| 添加 FAQ | 后台 → FAQ 管理 | superadmin / dept_admin / operator |
| 上传文档 | 后台 → 文档管理 | superadmin / dept_admin |
| 审核文档 | 后台 → 审核中心 | superadmin / dept_admin |
| 查看反馈 | 后台 → 用户反馈 | superadmin / dept_admin |
| 处理未命中 | 后台 → 未命中问题 | 管理员 |
| 修改词库 | 后台 → 词库管理 | superadmin / dept_admin |
| 配置权限 | 后台 → 角色权限 | superadmin |

---

## 四、角色说明

| 角色 | 权限范围 | 适用人员 |
|------|---------|---------|
| superadmin | 全部权限 + 所有 scope | IT 管理员 |
| dept_admin | 本部门文档管理 + public+internal scope | 部门主管 |
| operator | FAQ/文档编辑 + public+internal scope | 内容运营 |
| readonly | 仅查阅 public scope | 普通员工 |

## 五、常见问题

**Q: 搜索结果不准确？**
A: 检查"未命中问题"是否有类似问题，补充 FAQ 或文档。

**Q: 如何批量导入已有知识？**
A: 联系管理员使用 `import_seed_data.py` 脚本从 CSV 批量导入。

**Q: 文档更新后搜索结果未变化？**
A: 文档审核通过后会自动同步向量索引，约 1-3 分钟生效。

**Q: 敏感词拦截了正常问题？**
A: 进入"词库管理" → 删除对应的敏感词即可。
