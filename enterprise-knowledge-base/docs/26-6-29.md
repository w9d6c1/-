## 📌 任务描述

**项目名称**: 企业私有化知识库与双智能体系统

**总目标**: 基于「统一业务数据库 + 三向量集合物理隔离」架构，用 **LangChain + LangGraph** 搭建私有化知识库系统，实现内部问答智能体与客服智能体。6阶段28天开发周期。

**当前进度**: 阶段一(基础环境)和阶段二(后台管理)已全部完成，**即将进入阶段三(AI能力层)**。

## ⚠️ 必要背景

### 技术栈
- 后端: Python FastAPI + SQLAlchemy(async) + LangChain + LangGraph
- 前端: Vue3 + Element Plus + Pinia + Vue Router + Vite
- 数据库: MySQL 8.0 + PostgreSQL + Redis + Milvus 2.4 + Elasticsearch 8.x
- 存储: MinIO
- 监控: Prometheus + Grafana + Loki + Promtail
- 全部 Docker Compose 容器化，位于 `C:\Users\TLD\Desktop\知识库\enterprise-knowledge-base\`

### 运行环境关键约束
- 系统: Windows + Docker Desktop
- 本地有 HTTP 代理 `127.0.0.1:7897`（但不完全可靠）
- **pip 安装必须使用清华镜像源**: `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- bcrypt 版本必须 `<4.0`（passlib 1.7.4 与 bcrypt 5.x 不兼容）
- email-validator 必须额外安装（Pydantic EmailStr 依赖）

### Element Plus 已知坑
- `element-plus/dist/locale/zh-cn.mjs` 导入可能导致运行时崩溃，**不要导入 locale，Element Plus 默认就是中文**
- `<el-icon>` 组件需要显式 import 对应 icon，否则白屏。已从 AdminLayout 中移除 icon 标签

### 编码规范
- Python: PEP 8, ruff(fix已执行), mypy(剩余格式问题忽略)
- 不可变性优先，Service层分离业务逻辑
- JWT 密钥来自环境变量 `.env`，无硬编码密钥
- 所有异常不泄露栈跟踪
