## 已完成内容

### 1. 后端数据模型（`backend/app/articles/models.py`）

新增 `Photo` 和 `BatchPhoto` 两个 ORM 模型（WritingTemplate 之前）：

```python
class Photo(Base):
    """照片资产库"""
    __tablename__ = "photo"
    __table_args__ = (
        Index("idx_p_user", "user_id"),
        Index("idx_p_created", "created_at"),
    )
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    object_name: Mapped[str] = mapped_column(String(500), nullable=False)
    filename: Mapped[str] = mapped_column(String(200), nullable=False)
    tags: Mapped[list] = mapped_column(JSON, default=list)
    description: Mapped[str | None] = mapped_column(Text, default=None)
    file_size: Mapped[int] = mapped_column(Integer, default=0)
    content_type: Mapped[str] = mapped_column(String(50), default="image/jpeg")
    user_id: Mapped[int] = mapped_column(Integer, nullable=False)
    created_at / updated_at: DateTime

class BatchPhoto(Base):
    """批次-照片关联"""
    __tablename__ = "batch_photo"
    __table_args__ = (
        Index("idx_bp_batch", "batch_id"),
        Index("idx_bp_photo", "photo_id"),
        Index("idx_bp_used_at", "used_at"),
    )
    id: Mapped[int]
    batch_id: Mapped[int]
    photo_id: Mapped[int]
    article_id: Mapped[int | None]
    used_at: Mapped[datetime | None]
```

### 2. Pydantic Schema（`backend/app/articles/schemas.py`）

新增：`PhotoUploadResponse`, `PhotoResponse`, `PhotoUpdate`, `PhotoMatchRequest`, `PhotoMatchItem`, `PhotoMatchResponse`, `BatchPhotoSelectRequest`

### 3. 照片业务层（`backend/app/articles/photo_service.py`）

核心方法：
- `upload_photo(file, user_id)` → MinIO 存储 → Vision API 分析 → 返回 AI 标签 + 描述
- `match_photos(topic, count, exclude_days)` → LLM 关键词匹配 + SQL 标签筛选 + 排除窗口期
- `suggest_tags(photo_id)` → 重新生成 AI 标签
- `list_photos/get_photo/update_photo/delete_photo` → CRUD
- `select_photos_for_batch(batch_id, photo_ids)` → 关联照片
- `mark_batch_photos_used(batch_id)` → 标记已用

Vision 分析 Prompt（`_TAG_PROMPT`）：要求返回 JSON `{tags: [...], description: "..."}`，标签覆盖场景/工艺/视角/材料。

### 4. API 端点（`backend/app/api/articles.py`）

新增 10 个端点（在现有 `/photos/{object_name:path}` proxy 之前注册）：

```
POST   /photos/upload                    — 上传到照片库
GET    /photos                           — 列表（分页 + 标签筛选）
GET    /photos/{photo_id}               — 详情
PUT    /photos/{photo_id}               — 编辑标签
DELETE /photos/{photo_id}               — 删除
POST   /photos/{photo_id}/suggest-tags   — 重新 AI 打标签
POST   /photos/match                     — 智能匹配
POST   /batches/{batch_id}/select-photos — 关联照片
```

`start_generation` 增加 `use_photo_library` 参数，`_run_generation_in_session` 支持构建 photo_ids 列表传给 `run_generation()`。

### 5. 生成流程集成（`backend/app/articles/service.py`）

`run_generation()` 新增 `photo_ids` 参数：
- 照片库模式：读取 `Photo.description` 复用，构造 `photo_object_names` + `photo_descriptions`
- 手动模式：走原有 Vision API 分析流程
- 生成完成后调用 `mark_batch_photos_used()` 更新 `used_at`
