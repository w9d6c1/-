# 2026-07-21 开发日志 — 批量文章生成器后端开发

## 今日完成

### 阶段一：数据库 + 配置 + ORM 模型

- **DDL**：在 `docker/mysql/init/01-schema.sql` 追加 3 张表
  - `article_batch` — 批量生成任务（主题、照片、状态、user_id FK）
  - `article` — 单篇文章（batch_id FK CASCADE、标题/正文/角度/字数）
  - `publishing_record` — 发布记录（article_id FK CASCADE、平台/状态/URL）
- **配置**：`app/core/config.py` 追加 10 个字段（视觉模型 4、文章生成 5、发布 3），`cors_origins` 追加 `:5174`
- **ORM**：`app/articles/models.py` — 3 个 SQLAlchemy 2.0 Mapped[] 模型，遵循现有 document.py 风格

### 阶段二：后端核心模块（5 个文件）

- **schemas.py**：10 个 Pydantic v2 模型（Batch/Article/Publishing/Platform/SSE），`from_attributes` 序列化
- **vision.py**：可插拔视觉分析 — ABC 抽象接口 + OpenAI 兼容实现，逐张 MinIO 下载→base64→分析→`del` 释放，API key 未配时降级占位文本
- **generator.py**：三步流水线 — 5 角度知识检索（hybrid_retrieve）→ LLM 规划角度（失败回落默认）→ 逐篇生成（top-3 上下文、3s 间隔、`del` 释放）
- **publisher.py**：三层发布 — 微信公众号草稿 API（本地 access_token 缓存 7000s）、Wechatsync CLI subprocess、DOCX/HTML/MD 导出
- **service.py**：`ArticleService` 业务层（遵循 DocumentService 模式）— CRUD + `run_generation` 后台任务 + 发布编排 + ZIP 批量导出

### 阶段三：API 路由 + 注册

- **`app/api/articles.py`**：18 个 REST 端点（`/api/admin/articles/` 下）
  - 批次 CRUD：POST/GET/DELETE
  - 照片上传：POST（格式/大小校验，MinIO 存储）
  - 生成控制：POST 启动 + GET SSE 进度推送
  - 文章 CRUD：GET/PUT/DELETE + POST regenerate
  - 发布：单篇/批量 + 状态查询 + 平台列表
  - 导出：单篇(MD/HTML/DOCX) + 批量 ZIP
- **路由注册**：`app/api/admin/__init__.py` 追加 2 行（import + include_router），零修改现有代码

### 阶段四：后端测试（28 个用例）

- 单元测试（20 个）：生成引擎 8、视觉分析 5、发布服务 7
  - 覆盖正常流程、失败回落、权限验证、内存安全
