## 📌 项目概述

**项目名称**: 企业私有化知识库与双智能体系统

**总目标**: 基于「统一业务数据库 + 三向量集合物理隔离」架构，用 LangChain + LangGraph 搭建私有化知识库系统，实现内部问答智能体与客服智能体。

**本次阶段**: 阶段四（知识闭环优化）— P0 客服 API + 审计日志 + Chat UI，P1 FAQ 向量刷新 + 反馈 + 未命中 + 自动同步，P2 管理后台全部前端页面补全。

---

## ⚠️ 必要背景

### 技术栈
- 后端: Python FastAPI + SQLAlchemy(async) + LangChain + LangGraph
- 前端: Vue3 + Element Plus + Pinia + Vue Router + Vite
- DB: MySQL 8.0 + PostgreSQL 16 + Redis 7 + Milvus 2.4 + Elasticsearch 8.x
- 存储: MinIO | 监控: Prometheus + Grafana + Loki + Promtail
- 全部 Docker Compose 容器化

### 项目路径
```
C:\Users\TLD\Desktop\知识库\enterprise-knowledge-base\
```

### 运行环境关键约束
- 系统: Windows + Docker Desktop
- **pip 必须使用清华镜像源**: `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- **bcrypt 必须 <4.0**（passlib 1.7.4 与 bcrypt 5.x 不兼容）
- **email-validator 必须额外安装**（Pydantic EmailStr 依赖）
- **psycopg-binary 必须额外安装**（LangGraph PostgresSaver 依赖）
- **aiosqlite 必须额外安装**（测试 SQLite 依赖）
- 修改代码后容器需 `docker compose restart backend` 或 `--force-recreate`

### Element Plus 已知坑
- **不要导入** `element-plus/dist/locale/zh-cn.mjs`（运行时崩溃，默认就是中文）
- `<el-icon>` 需显式 import 对应 icon

### 编码规范
- Python: PEP 8, 不可变性优先, Service 层分离业务逻辑
- JWT 密钥来自 `.env`, 无硬编码密钥
- 所有异常不泄露栈跟踪
- TDD 强制: 先写测试(RED) → 实现(GREEN) → refactor → code-reviewer

### 测试约束
- 测试用 SQLite 内存 DB（`conftest.py`），不依赖 MySQL/Milvus
- 测试中需 mock HuggingFace embedding 网络调用（`embed_query`/`embed_texts`）
- 运行命令: `python -m pytest tests/unit/ -q --no-cov --asyncio-mode=auto --ignore=tests/unit/test_checkpoint.py`
