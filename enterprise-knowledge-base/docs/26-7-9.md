## Phase 4：RBAC 修复 — 注册接口强制 readonly 导致测试失败

**根因**：`backend/app/api/admin/auth.py:70` 硬编码 `payload.role = "readonly"`，导致所有通过 `/auth/register` 注册的用户无论请求中指定什么角色都强制为 readonly。影响 7 个测试。

**修复方案**：生产安全方案 B — 注册接口保持不变（安全设计），新增 `POST /api/admin/users` 端点（superadmin 专用），测试改用 conftest 的 `token_factory`（service 层直接创建）。

| 文件 | 改动 |
|------|------|
| `backend/app/core/dependencies.py` | +`require_superadmin = require_role("superadmin")` |
| `backend/app/api/admin/auth.py` | +`POST /api/admin/users` (require_superadmin, 保留指定 role) |
| `tests/e2e/test_full_pipeline.py` | 5个测试：`_register_superadmin` → `_register_superadmin_via_token_factory` |
| `tests/integration/test_audit_chain.py` | 5个测试：`_login()` 改用 `token_factory` 创建 superadmin |

**修复后**：
- E2E 全流程: 0/5 → **5/5 PASSED**
- 审计链路: 3/5 → **5/5 PASSED**
